# Data

- `cmudict.dict`: the CMU Pronouncing Dictionary (Carnegie Mellon University,
  BSD-style licence, see `CMUDICT-LICENSE`). Word → ARPAbet phonemes.
- `wordfreq.txt`: the 40,000 most frequent words and their counts, from Peter Norvig's
  `count_1w.txt` (Google Web Trillion Word Corpus counts, https://norvig.com/ngrams/,
  MIT licence). Word, space, count.
