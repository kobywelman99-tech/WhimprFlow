# Recording the eval clips

Generated by `cargo run -p whimpr-eval -- --write-recording eval/RECORDING.md`. Do not edit by hand; edit `eval/fixtures/manifest.json` instead.

## How

- Save each clip into `eval/fixtures/` with **exactly** the file name shown. Any WAV works: 16-bit or float, any sample rate, mono or stereo (16 kHz mono is ideal).
- One take each, at your normal pace and volume, sitting where you normally dictate. Leave about half a second of quiet before and after, **except** the *very-short* clips, where you start right away and stop immediately.
- Say the words in the **Say** column. Don't read the punctuation aloud; say "new line" only where it's written.
- Quiet room for everything except the *noisy* clip.
- Check progress any time: `cargo run -p whimpr-eval -- --list-missing`.

The eval dictionary contains: ChargeBee, Manvi, Kubernetes, WhimprFlow, Priya Raghunathan.
