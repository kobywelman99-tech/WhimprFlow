## Word frequencies (built in)

How common each English word is. Derived from the Google Web Trillion Word Corpus, as published in the `count_1w.txt` file that accompanies Peter Norvig's "Natural Language Corpus Data" (https://norvig.com/ngrams/), which describes the data as distributed by the Linguistic Data Consortium. Norvig's MIT licence on that page covers his code; the licence status of the counts themselves has not been settled.
